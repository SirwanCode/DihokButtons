# DihokButtons

A collection of 46 modern button components built entirely with Pure CSS.

DihokButtons is a lightweight CSS button library that provides beautiful, responsive, and customizable button styles without JavaScript, frameworks, or external dependencies. Simply copy the HTML and CSS into your project and start building.

## :sparkles: Features

- 46 unique button designs
- Built with Pure CSS
- No JavaScript required
- No frameworks or libraries
- Easy to customize
- Modern hover and transition effects
- Ready to use

## :package: Installation

Clone the repository:

bash
git clone https://github.com/SiranCode/dihokbuttons.git


Or download the ZIP file and include the CSS DihokButtons.css in your project.

 ```html
 <link rel="stylesheet" href="css/DihokButtons.css">
```

## :book: Usage

 
 🔹sample usage(for button-003)
 ```html
 <button class="dButton-003 dButton-003-red">Button</button>
```
    

🔴to change color, just replace class "dButton-003-blue" with one the following
